# 遥感概论学习站

基于《遥感概论（第二版）》及课程资料整理的本科复习站，包含章节知识、课件例题、交互演示和课后题精选。

- 在线站点：https://remote-sensing-study-1125.biss0.chatgpt.site
- 公式采用 MathJax 3（加载失败时保留浏览器原生 MathML），图片浏览使用 Fancybox 3。
- 站点是静态文件，网页位于 `dist/`。Vercel 导入后可直接部署，输出目录为 `dist`。
- 本地预览：`python3 -m http.server 8000 --directory dist`。
- 手机端底部快捷栏与章节抽屉；提供思维导图、知识图谱、名词解释与思考题卡片，以及支持筛选和标记待加强的随机抽卡。
- 复习进度及待加强标记保存在当前浏览器；第三方脚本需要访问 jsDelivr。
- 内容标有来源页码与核验状态；课件原题仍未全部逐页核对。

## 安装与离线使用

- 使用 HTTPS 打开站点，浏览器支持时可通过菜单安装或添加到主屏幕。iPhone/iPad 可在 Safari 的分享菜单中选择“添加到主屏幕”。
- 首次联网并完成缓存后，可离线浏览已缓存的章节、卡片、题目和站内图片；公式排版与图片放大组件需联网成功缓存，部分外部字体或组件可能需要再次联网。
- 在线时优先获取最新站内文件，网络不可用时回退到缓存；缓存受浏览器存储空间和清理策略影响。复习进度仅保存在当前浏览器或已安装应用的数据空间，请勿依赖缓存作为备份。
